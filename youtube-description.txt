PICO 2 MMBASIC WORKSTATION - BUILD GUIDE

A small, portable standalone computer built from a Raspberry Pi Pico 2 W running
MMBasic Anywhere. Built-in 5" 640x480 display, USB keyboard, and 18650 battery
power. It boots in about a second. Video out, SD card
storage, and audio through a class-D amp and speaker.

FIRMWARE

Download and flash this UF2:
https://github.com/jvanderberg/PicoMiteAllVersions/releases/download/latest/PicoMite-DVIWIFIRP2350.uf2

Hold BOOTSEL while plugging the Pico into your PC. It mounts as a drive called
RPI-RP2. Drag the .uf2 onto it. The Pico reboots into MMBasic.


WIRING

The HDMI output claims GP12-GP19, so everything else routes around them.

microSD module -> Pico
  SCK / CLK      -> GP10 (pin 14)
  MOSI           -> GP11 (pin 15)
  MISO           -> GP8  (pin 11)
  CS             -> GP9  (pin 12)
  VCC            -> 3V3 OUT (pin 36)
  GND            -> GND

MAX98357A amp -> Pico
  BCLK -> GP20 (pin 26)
  LRC  -> GP21 (pin 27)   (must be BCLK + 1)
  DIN  -> GP22 (pin 29)
  Vin  -> 5V rail (XL6009 #2 / Pico VBUS)
  GND  -> GND
  GAIN -> leave floating (9 dB default)
  SD   -> leave floating (mono mix)

Speaker -> MAX98357A + and - terminals (polarity does not matter)

DVI Sock: mounts directly on the Pico (GP12-GP19). HDMI cable from the Sock to
the LCD control board's HDMI input.

USB keyboard: plug the OTG adapter into the Pico's micro-USB port, then the
keyboard into the adapter.

POWER (battery + two converters)

  2S 18650 pack (~7.4V) -> XL6009 #1 set to 12V -> LCD control board
                        -> XL6009 #2 set to  5V -> Pico VBUS (pin 40) + amp Vin
  pack GND -> common GND (LCD, Pico pin 38, amp)

Set each converter's output with a multimeter before connecting its load: 12.0V
on #1, 5.0V on #2. Feed 5V to VBUS (not VSYS): the Pico hosts the USB keyboard,
which draws power from VBUS, and that 5V also back-feeds VSYS to run the Pico.
Tie all grounds together.

Safety: a bare 2S holder has no charge protection or balancing. Use protected
cells and a proper 2S charger, or add a 2S BMS. Do not charge unbalanced Li-ion
unattended.


CASE

3D-printed enclosure: "Mini IBM PC (working clone!)"
  https://www.thingiverse.com/thing:7149915
Print it and customize to suit your layout, drilling or cutting openings as
needed:
- Expose the SD card slot at an edge using the microSD-to-SD extender, so you can
  swap cards without opening the case.
- Add a port for the USB keyboard's OTG connector.
- Expose the display control board's buttons, or leave them inside.


FIRST-BOOT CONFIG (type once at the > prompt; saved to flash)

  OPTION SDCARD GP9, GP10, GP11, GP8     ' CS, CLK, MOSI, MISO
  OPTION AUDIO I2S GP20, GP22            ' BCLK, DIN (LRCLK auto = BCLK+1)

The display needs no config. The HDMI build boots into 640x480 (MODE 1, about
80x40 text) automatically. Use MODE 3 for 16 colours; FONT changes text size.
