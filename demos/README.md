# Demos

MMBasic programs for the workstation. Copy any of these to the SD card and run
them with `RUN "filename.bas"` (or `LOAD` then `RUN`).

## Games and graphics

| File | What it is |
|------|------------|
| `picoblocks.bas` | Breakout-style paddle-and-bricks game, framebuffer double-buffered. |
| `Picovaders.bas` | Space Invaders clone by Martin Herhaus. |
| `demo.bas` | Pong with paddle inertia and framebuffer double buffering. |
| `mand.bas` | Mandelbrot renderer with a menu, pure BASIC. |
| `matrix.bas` | Matrix-style falling-character effect. |

## Drawing (direct-draw, no framebuffer)

| File | What it is |
|------|------------|
| `demo_draw_bounce.bas` | Bouncing balls, direct draw. |
| `demo_draw_clock.bas` | Analog clock, direct draw. |
| `demo_draw_paint.bas` | Incremental paint pattern, direct draw. |
